# Dream Pet MVP

Премиальная стартовая версия pet marketplace для поиска щенков от питомников и заводчиков.

## Запуск локально

```bash
npm install
npm run dev
```

## Публикация на GitHub Pages

В проекте уже есть:

- `vite.config.js` с `base: '/dream_pet/'`
- `.github/workflows/deploy.yml`

После загрузки файлов в репозиторий включите GitHub Pages:

`Settings -> Pages -> Source -> GitHub Actions`

Сайт будет доступен по адресу:

`https://mburzhinsky-hub.github.io/dream_pet/`
